# AI-Customer-Support-Agent-with-Escalation
A smart Customer Support Agent that answers queries and automatically detects user frustration. If the user is angry, it triggers an Escalation Logic to transfer them to a human agent.

## 🛠️ Tech Stack
Backend Logic: Python
Frontend UI: HTML, CSS, JavaScript (Terminal Design)

## Features
Conversational AI: Handles basic user queries.
Sentiment Analysis: Detects frustration keywords (e.g., "stupid", "manager", "angry").
Smart Escalation: Automatically creates a support ticket and alerts a human agent.
Terminal UI: A retro-style chat interface that mimics a real coding environment.
